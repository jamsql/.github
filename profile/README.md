## Jam SQL Studio

Jam SQL Studio is a desktop SQL IDE for SQL Server, PostgreSQL, MySQL and MariaDB, Oracle and SQLite. It also
queries Azure Data Explorer (Kusto) and browses Azure Storage. It runs on macOS, Windows and Linux.

- Query Editor with IntelliSense, execution plans, result grids and charts
- Table Explorer for browsing, filtering and editing rows
- Schema compare and data compare, with generated scripts
- SQL notebooks
- A local MCP server: Claude, Cursor, VS Code and other AI tools work with your saved connections through the app.
  The AI tool never receives connection credentials, and each write waits for your approval in Jam SQL Studio.

Jam SQL Studio is free for personal, non-commercial use. [Pro](https://jamsql.com/pricing/) adds the license for
commercial use.
